# Changelog

All notable changes to the Greek Scholarly Reader are documented here.

## [6.2.0] - 2026-10-16

### Added
- Interactive Greek dictionary popup.
- Click-to-inspect functionality for Greek words.
- Floating definition cards.
- LSJ dictionary lookup integration.
- Clickable suggested Greek headwords.
- Selected-word highlighting.
- Escape-key and close-button support.
- Synchronization between popup and dictionary inspector.

### Improved
- Greek and English passage highlighting.
- User interaction with Greek vocabulary.
- Dictionary suggestion navigation.
- Parallel Greek-English reading experience.

### Fixed
- Dictionary information not appearing when clicking Greek words.
- Suggested headwords not triggering dictionary lookups.
- Word inspection requiring users to locate an off-screen panel.

## [6.1.0] - 2026-10-16

### Added
- Greek word highlighting.
- English search-term highlighting.
- Manual Greek stem highlighting.
- English-to-Greek lexical suggestions.

## [6.0.0] - 2026-10-16

### Added
- Greek-English passage alignment.
- Canonical book, chapter, and section references.
- Separate SQLite alignment index.
- Bilingual scholarly search interface.

### Fixed
- Incorrect Greek-English passage pairings.
- Ambiguous numeric passage references.

## [5.0.0] - 2026-10-16

### Added
- Initial XML-based passage alignment builder.

### Known Issues
- Original alignment parser failed to recognize some XML structures.
- Initial alignment build mapped zero passages.

## [4.0.0] - 2026-10-16

### Added
- Fuzzy Greek dictionary search.
- Character trigram matching.
- Greek word bigram analysis.
- Greek word trigram analysis.
- Greek word inspector.
- LSJ dictionary suggestions.
- Parallel-text reading interface.

## [3.0.0] - 2026-10-16

### Added
- Initial Greek word inspector.
- Experimental parallel Greek-English reading.
- Greek spelling suggestions.

## [2.0.0] - 2026-10-16

### Added
- Scholarly source metadata.
- Author and work title resolution.
- LSJ dictionary integration.
- Perseus lexicon integration.
- Author-filtered passage search.

## [1.0.0] - 2026-10-16

### Added
- SQLite FTS5 Greek search.
- First1KGreek ingestion.
- Homeric Hymns ingestion.
- Ancient Greek accent normalization.
- Initial JSON search API.
